NeverApply is an AI-powered job search agent that automates the entire application process. It scans public job listings, curates matches, tailors applications, and submits them on behalf of users, handling resumes, cover letters, and interview preparation. The service offers a free tier with ten applications and paid plans for unlimited job hunting, aiming to eliminate repetitive manual job applications and improve candidate efficiency.

**Areas:** AI · JobSearch · Automation · Recruitment · SaaS

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for NeverApply: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
